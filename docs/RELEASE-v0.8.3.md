# Nocturnis 0.8.3 — kamienne posadzki

Akt I, Windows x64. Wydanie zawiera trzy zestawy zużytego kamienia z materiałami PBR, ciągłe powierzchnie podłóg w 12 wnętrzach oraz poprawione osadzenie metalowych krat.

- **Nocturnis-0.8.3-Windows-x64.zip** — gotowa gra. Rozpakuj wszystko i uruchom GRAJ.cmd.
- **Nocturnis-0.8.3-Unity-project.zip** — kompletny projekt Unity 6000.3.26f1 z modelami, teksturami, dźwiękiem i scenami.
- **Nocturnis-0.8.3-kamienne-posadzki.pdf** — rzeczywiste zrzuty gry.
- **SHA256SUMS.txt** — sumy kontrolne pobranych plików.

Automatyczne archiwa GitHub „Source code” zawierają kod i konfigurację z Git. **Pełne zasoby są w nazwanym archiwum Unity-project.zip.** W klonie można je przywrócić skryptem tools/restore_project.py.

Kontrola wydania: powierzchnie w 12 wnętrzach, zrzuty siedmiu lokacji, niski profil grafiki, start i sesja gry. Zapisy pozostają poza katalogiem wydania. Jest to wersja rozwojowa Aktu I.
