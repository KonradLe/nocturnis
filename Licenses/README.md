# Component authors and licences

Version 0.8.4. This directory preserves component licences and attribution; it does not place the entire game under an open-source licence.

- KayKit / Kay Lousberg, Kenney and Universal Animation Library Standard / Quaternius: CC0; original licence texts are included.
- Poly Haven: CC0; monastery_stone_floor, slate_floor_02 and stone_floor surfaces, plus earlier stone materials.
- Rakshi Games, Tree 10 / Tree 12: CC BY 3.0; attribution and modification notes are preserved.
- DejaVu Serif: the original font licence is included.
- CC0 sounds: authors and source links are recorded in current-source-notices/Assets/StreamingAssets/Nocturnis-Audio-Credits.txt.
- Nocturnis models, materials and UI: TRELLIS.2 reconstructions, Blender models and images generated for the project.
- Cinematics: previously generated imagery/video and narration. The English intro reuses the repaired audio and clean footage with new subtitle/title text; no new AI generation was used for 0.8.4.
- Unity/glTFast and related package notices: previous-notices/package-notices.

Current in-game attribution is copied to current-source-notices/Assets/Resources/Credits.txt and Credits-en.txt. Historical files retain their original dates and version numbers. Credits-Nocturnis-0.7.0.txt describes an earlier iteration, not the complete current release.

The historical Xali model includes the author's notes on an external base mesh and texture. Those notes are preserved without expanding the stated permissions. It is not the current Inquisitor model.

The repository and complete asset archive remain private. No blanket licence has been granted to publicly redistribute all raw assets.
